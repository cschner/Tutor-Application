# Tutor Application

A desktop app for tutors to manage student info, schedules, and accounts. Built with Python and Tkinter.

## What It Does

- **Login System** - Username/password authentication with admin accounts
- **Student Profiles** - Create, view, and edit student information (name, class, grade, notes)
- **Scheduling** - Add, edit, and delete tutoring sessions with dates, times, and tutor names
- **Search** - Find students quickly with name search and autocomplete
- **Admin Tools** - Create new accounts and change passwords (admin only)
- **Persistent Storage** - Everything saves to JSON files

## How to Run

### Requirements
- Python 3.7+
- Pillow (for images): `pip install Pillow`

### Start the App

python Main.py
